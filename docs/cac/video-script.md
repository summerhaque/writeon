# Write On! · Demo video script

> **Replace this with Summer's latest ~3-minute script once it's in hand.** This draft was written before the brand and copy revamp. Its facts are now corrected: the real app is built with React on Base44 and calls an AI model for the coach. The click path below follows the Expo demo build.

**Length:** about 2:45. CAC requires 1 to 3 minutes, so don't go over.
**Format:** a screen recording of the app, with Summer's voiceover. A few seconds of Summer on camera at the start and end is a nice touch, but optional.
**Upload:** YouTube or Vimeo, set to **Public**.

The rules require the video to cover six things. Each is marked below where it happens:
① participant names · ② app name · ③ purpose in one clear sentence · ④ target audience · ⑤ tools and languages · ⑥ the app working

---

## Before you record

- In the app, go to **Progress → Settings → Erase everything and start over**, then sign in with the pen name **Summer**. That puts the demo story, *The Tower of Fibs*, on the desk.
- Use light mode, turn on Do Not Disturb, and charge the phone. On a Mac you can record the simulator with `xcrun simctl io booted recordVideo writeon-demo.mp4`.
- Practise the taps once. Don't rush them: judges need to see what happens.
