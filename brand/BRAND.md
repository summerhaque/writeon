# Write On! — Brand

*Everyone has a story worth telling.*

Warm paper, real ink, one vermilion nib. Literary, not cartoony.

## Files
- `writeon-logo-light.svg` / `writeon-logo-dark.svg`: the feather, for light / dark backgrounds
- `writeon-logo-slogan-light.svg` / `writeon-logo-slogan-dark.svg`: feather + name + slogan
- `writeon-app-icon.png`: app icon, 1024×1024
- `favicon.svg`, `favicon.ico`: website

The nib is always vermilion. Don't recolor, stretch, or add effects.

## Fonts (Google Fonts)
- **Fraunces**: logo, headings, and the student's story text
- **Source Sans 3**: all UI
